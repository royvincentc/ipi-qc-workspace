# IPI report tag placement previews

Seven DOCX previews use real logbook identifiers across May through August 2026. Report generation date/time is shown as 09/30/2026 @ 02:55 PM. Received dates use MM/DD/YYYY; records without a reliable timestamp are left blank. Empty sample suffixes omit the surrounding parentheses.

Actual result and product-specific acceptance-criteria cells remain blank because the IPI Results workbook has no populated rows for these samples. Test labels are from the applicable product records. Historical rows do not have sample-name suffix, manufacturing/expiry date, fill volume, batch size, page number, and some do not have Received By/Analyst values. These fields remain blank instead of being inferred. MIC values use the October Analyst table where a logged analyst is available.

Both SFG templates are included because historical per-parameter analyst marks are unavailable. Both RM templates are included because the historical row does not expose its Supplier toggle. Product Stability uses the logged Type value Actual.
